# NeuroPet 2D v0.1.0

Windows x64 便携版，解压 ZIP 后双击 `NeuroPet-2D.exe`。整个文件夹可移动，保存 EXE 与 `_internal/` 在一起。

- 桌面同时显示最多 10 只蟑螂 / 果蝇，旧 3 宠配置自动升级。
- 新面板直接添加、投喂、暂停、隐藏 / 召回，支持全部暂停与滚动列表；记忆 / 设置按需打开。
- 保留原来的 2D 身体与步态，图像缓存按字节淘汰；位置移动和姿态绘制分开，重叠合成按帧批处理。
- 默认一蟑螂一果蝇，存档在 `data/`，关闭面板后从系统托盘恢复；退出时保存。
- 附项目与依赖许可证、pystray 的 Python 源码轮子。原研究目录未修改，发行包不包含私人存档或日志。

60 MiB 优化目标尚未达到。双宠便携候选 5 分钟：工作集约 87 MiB；10 宠源码短测约 83 MiB（未加载托盘），口径见仓库的 `docs/performance.md`。按用户要求停止追加审查与测试，保留已完成的验证结果。
