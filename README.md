# NeuroPet 2D

拟真的 Windows 蟑螂 / 果蝇桌宠。六足步态、触角探测、清洁身体、觅食和对鼠标的反应；保留原来的 2D 运动，专注轻量桌面体验。

## 使用

1. 下载 Release 的 ZIP，解压到可写的文件夹，双击 `NeuroPet-2D.exe`。无需安装 Python。
2. 启动默认是一只蟑螂和一只果蝇。点击 **添加蟑螂 / 添加果蝇**，桌面最多同时显示 **10 只**。旧配置里的 3 宠上限会自动升级。
3. 选中列表中的宠物，直接 **喂它、暂停、隐藏**。隐藏保留记忆，再点 **召回** 即可回来；名额已满会提示。
4. 按住虫体可以拖动。**全部暂停 / 全部继续** 控制整个桌面；列表滚动不会改变选中的宠物。
5. 关闭面板后宠物继续活动。右键系统托盘图标可重新打开面板、放食物或保存退出；托盘不可用时从任务栏恢复。

`Ctrl+1 / Ctrl+2` 添加两种宠物；列表中按空格暂停当前宠物，Esc 收起面板。**设置**可以调整宠物显示大小、全局爬行速度、拖尾、开机自启动、启动面板和界面语言；**记住的事**按需打开。移除只移出当前会话，档案保留；清除记忆会二次确认。

**设置**里的每一项都**改完立刻生效并保存**，没有保存按钮：语言、宠物大小、爬行速度、拖尾、开机自启动、启动时打开面板各自独立生效，窗口底部会写明"改动会自动保存"。设置里还有一个**当前宠物**下拉，切换它就能改那只宠的大小；没有预先选中宠物时会自动关联第一只可见宠物，隐藏的宠物也会列出并附"召回它"按钮，不必回主面板去找。"保存并退出程序"已去掉，底部按钮是**关闭设置**——Esc、右上角 X 和这个按钮都只关设置窗口，程序和宠物照常运行；要退出请用系统托盘菜单的**退出**。

投喂模式开着时下拉框也能正常点选：程序界面（包括下拉弹出的列表）都被算作可点击区域，全局鼠标钩子不会把点击下拉项当成"点在桌面上"。

## 爬行速度与鼠标反应

- **全局爬行速度**：设置里选 **0.5× / 1× / 2× / 3× / 4× / 6× / 8×**，默认 **2×**（比原来明显更快），立即生效并保存，重启后恢复。它同时放大巡航、逃跑上限和加速度，也与食物带来的临时加速叠加；**只改运动参数，不改全局节拍**，所以饥饿、记忆、食物和飞行的节奏照旧。升降档时宠物保持当前位置、朝向和步态相位，只是有限地加减速，不会突然跳动。
- **鼠标逼近 = 风压**：鼠标越快朝宠物冲过来，风压越强、宠物逃得越快（1× 时最高约 1.6 倍）；鼠标静止或远离时风压为零，擦身而过只留一点空气扰动。反应仍带文献里的"急停僵住 → 转身 → 冲刺 → 减速警戒"，果蝇的起飞反应保持不变。
- **高速拖尾**：跑得够快时脚下出现一条细线，越快越长（上限约 240 像素，每只最多 4 段），停下后约 0.15 秒内收回。默认开启，可在设置里关闭。

## 语言

界面、设置、记忆窗口与系统托盘菜单都提供 **简体中文 / English**，在 **设置 → 语言** 切换，立即生效并保存，无需重启。首次运行没有语言配置时跟随系统语言：中文系统用中文，其余用英文，检测失败回退中文。切换语言不会打断当前操作：选中的宠物、编号、已选食物、暂停与隐藏状态、已打开的窗口都原样保留，用户自定义的宠物名字不翻译。

**记忆正文保持原文**：宠物自己写下的历史经历是存档内容，不做机器翻译、不重写，因此早期存档在英文界面下仍显示原来的语言。

当前支持 Windows 10/11、主显示器。透明背景可穿透到桌面，虫体保留拖动交互。桌面点击投喂默认 15 秒自动结束，面板内直接投喂无需开启这个模式。

## 边界与开机自启动

- 宠物只在**可用桌面**内活动：程序读取 Windows 当前显示器的真实工作区，任务栏在底部、顶部、左侧或右侧都适用，不再写死任务栏高度。靠近边缘会提前减速，碰边沿边滑行，不会瞬移；任务栏自动隐藏或工作区变化时，宠物按正常速度自己走回可用区域。
- **开机自启动 / Start with Windows**（设置里的独立复选框，默认关闭）只写 `HKEY_CURRENT_USER\...\Run`，不需要管理员权限，只删改本程序那一个值。勾选后 Windows 登录时会自动启动并直接进入系统托盘（不弹控制面板）；手动双击仍然按"启动时打开控制面板"那个开关决定。**便携文件夹换了位置之后要重新勾选一次**，否则勾选框会显示未开启（因为注册表里还是旧路径）。

## 存档

`data/` 在 EXE 旁保存配置、宠物名册、隐藏状态和每只宠物的记忆。配置里的 `crawl_speed` 保存爬行速度档位，`trail_enabled` 保存拖尾开关。更新时关闭旧程序，保留这个目录，用新 EXE 替换旧 EXE。可用环境变量 `NEUROPET_DATA_DIR` 指定其他存档目录。

开机自启动**不存进 `data/`**：注册表本身就是唯一依据，程序每次打开设置都直接读它，不会把"配置里写了 true"当成"系统已注册"。

公开源码和发行包包含步态参数，不包含研究目录里的私人存档、日志或 Git 历史。原 NeuroPet 研究目录保持原样。

## 开发 / 打包

需要 Windows 和 Python 3.13（含 tkinter）：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe -m neuropet.main
.venv\Scripts\python.exe tools\run_all_tests.py
.venv\Scripts\python.exe tools\build_release.py
```

`start.bat` 使用本地虚拟环境或 PATH 中的 Python；`build_exe.bat` 输出 `dist/NeuroPet-2D/` 便携文件夹。保持 EXE 与 `_internal/` 一起移动，双击 EXE 即可；此打包方式只需要一个常驻进程。运行依赖为 Pillow / pystray，未引入浏览器界面或 3D 驱动。

界面文案集中在 `neuropet/core/i18n.py` 的内置字典（zh-CN / en，无新增第三方依赖）；新增文案加一个 key 即可，两种语言同时给出。`data/config.json` 的 `language` 字段保存用户选择，缺失时按系统语言判定。

v0.2.0 的可用桌面口径在 `neuropet/core/desktop.py`（Win32 `MonitorFromPoint` + `GetMonitorInfo` 的 `rcWork`，非 Windows 回退整屏），身体软墙、拖拽仲裁和面板落食都走它；高速拖尾在 `neuropet/render/trail.py`（Canvas 矢量线项，不产生位图）；开机自启动在 `neuropet/core/autostart.py`（stdlib `winreg`，无新增依赖）。

测量程序使用一次性存档，不触碰用户数据：

```powershell
.\NeuroPet-2D.exe --probe --pets 10 --seconds 60 --output result.json
python tools\release_probe.py --pets 2 --seconds 60 --output result.json
```

模拟更新与姿态重绘分开；宠物移动不必等待姿态绘制配额。图像缓存按字节淘汰，重叠宠物每帧合成一次；透明显示表面按实际内容调整范围。**60 MiB 是双宠优化目标，实际数据以性能报告为准，10 宠单独计量。** 英文说明见 [README.en.md](README.en.md)；性能报告为中英对照单文件 [docs/performance.md](docs/performance.md)。
